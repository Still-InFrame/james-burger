# Burger James cinematic website

A transferable one-page restaurant website built with plain HTML, CSS and JavaScript.

## Preview locally

Open `index.html` directly, or serve the folder with any static web server.

## Cinematic scroll hero

The hero uses `assets/burger-journey.mp4`, a 12-second 1080p Seedance film. JavaScript maps the hero section's scroll progress directly to the video's `currentTime`, allowing visitors to travel forward and backward through the burger. The film is encoded as H.264 with frequent keyframes and fast-start metadata for responsive browser seeking.

## Deploy

Upload this folder to Cloudflare Pages, Netlify, Vercel, GitHub Pages, or any conventional web host. No database or server runtime is required.

## Client handoff

1. Put the folder in a Git repository owned by Burger James.
2. Deploy from the client's hosting account.
3. Connect a domain registered in the client's name.
4. Replace the phone-order CTA with the restaurant's preferred pickup/delivery URL when supplied.
5. Confirm operating hours before launch.

## Recurring costs

The site itself has no software subscription. The domain normally renews annually. Hosting may be free depending on provider and traffic. All photography and branding images are included locally; Google Fonts and GSAP are loaded from external CDNs.

## Content notes

The page uses the supplied address, phone number, rating, review count, amenities and review excerpts. Exact menu prices and ordering URLs were not supplied, so none were invented.
